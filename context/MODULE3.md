# Module 3 — Cross-Port Intelligence Dashboard

Sample dashboard design (Deliverable 4). Synthetic data labelled **ILLUSTRATIVE**.

## Design rules implemented

- Answers: where do we stand / what changed / what happens next
- All screens read `lib/data/store.ts` (one database)
- Status tiles, priority bands, and DQ warnings are **stored fields**
- Roles: port engineer, inspection team, management, platform admin
- Shared filters across screens
